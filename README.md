# IdleGame

클릭형 아이들 게임 (Clicker Idle Game)

## 기술 스택

- **Engine**: Unity 2D (URP)
- **Language**: C#
- **Version Control**: Git / GitHub

---

## 게임 개요

화면의 몬스터를 클릭해 데미지를 주고, 처치 시 골드·아이템을 획득한다.
골드로 스킬을 업그레이드하고 아이템을 장착해 스탯을 강화한다.
스테이지가 올라갈수록 몬스터가 강해지고 보스가 등장한다.

**코어 루프:** 클릭 → 처치 → 보상 → 강화 → 반복

## 현재 구현 상태

### 핵심 시스템

| 시스템 | 상태 | 설명 |
|--------|------|------|
| 몬스터 | ✅ | HP, 데미지, 드랍, 파티클, 클릭 처리 |
| 스테이지 | ✅ | 10존 × 10스테이지 구조, 보스 등장, 스테이지 선택 팝업 |
| 존 진행 | ✅ | 초원→숲→사막→동굴→설원→천공→고대유적→마계→공허→심연 |
| 도망 시스템 | ✅ | 골드 소모로 현재 몬스터 스킵, 컨펌 모달 |
| 플레이어 스탯 | ✅ | 클릭/자동 데미지, 공속, 골드배율, 드랍률, 크리티컬 |
| 재화 | ✅ | 골드, 보석 관리 |
| 업그레이드 | ✅ | 스킬 업그레이드 구매·효과 적용 (8종) |
| 인벤토리 | ✅ | 아이템 보유·장착·판매·드랍, 자동판매, 판매 컨펌 모달 |
| 아이템 드랍 | ✅ | 스테이지별 minDropStage 제한, 등급별 가중치 |
| 세트 아이템 | ✅ | 세트 효과 시스템 (자동공격 스킬 발동형) |
| 파티클 | ✅ | JSON 기반 이펙트 스폰, 그림자·타격 이펙트 |
| 오디오 | ✅ | BGM·SFX 재생 |
| 설정 | ✅ | 볼륨·진동·알림·데이터 초기화 |
| 저장 | ✅ | PlayerPrefs 기반 자동 저장 (골드/업그레이드/인벤토리/스테이지) |
| 밸런스 설정 | ✅ | GameConfig ScriptableObject로 수치 중앙화 |
| 개발자 패널 | ✅ | 어드민 패널 (골드 지급, 아이템 지급, 스테이지 이동 등) |

### 스킬 목록 (업그레이드)

| 분류 | 스킬명 | 효과 |
|------|--------|------|
| 클릭 (물리) | 강타 | 클릭 데미지 증가 |
| 클릭 (물리) | 분쇄 | 클릭 데미지 대폭 증가 (최대 20레벨) |
| 클릭 (물리) | 연격 | 클릭 데미지 증가 |
| 자동 (마법) | 파이어볼 | 자동 데미지 증가 |
| 자동 (마법) | 혼돈의 오브 | 자동 데미지 강화 |
| 자동 (마법) | 독안개 | 자동 데미지 증가 |
| 골드 | 황금 손길 | 골드 획득 배율 증가 |
| 골드 | 약탈의 기술 | 골드 획득 배율 증가 (최대 10레벨) |

### 아이템 드랍 구조

| 스테이지 | 드랍 등급 | 내용 |
|----------|-----------|------|
| 1~2 | Normal | 기본 장비 5종 |
| 3~6 | Rare | 레어 장비 (자객 세트 포함) |
| 5~6 | Unique | 유니크 개별 아이템 |
| 7~8 | Unique | 고급 유니크 |
| 9~10 | Unique | 정복자 세트 |

| 설정 팝업 | ✅ | 볼륨·토글·초기화·개발자 패널 |
| 아이템 토스트 | ✅ | 획득 시 등급별 색상 알림 |
| 스테이지 선택 | ✅ | 해금된 스테이지 선택 팝업 |
| 도감 패널 | ✅ | 획득한 아이템 도감 |
| 업적 패널 | 🚧 | 준비중 |

## 프로젝트 구조

```
Assets/
├── Scripts/
│   ├── Core/           # Monster, UIBoot, BackgroundManager
│   ├── Data/           # ScriptableObject 데이터 정의
│   │   ├── GameConfig.cs       # 밸런스 수치 중앙화 ★
│   │   ├── SetBonusData.cs     # 세트 효과 정의
│   │   ├── SetEffect.cs        # 세트 효과 추상 클래스
│   │   └── PeriodicSkillEffect.cs # 주기적 스킬 발동 효과
│   ├── Managers/       # 도메인 매니저
│   │   ├── PlayerStats.cs      # 스탯 계산 (기본 + 업그레이드 플랫 + 장비 %)
│   │   ├── MonsterManager.cs   # 스폰, 존/스테이지 진행, 보스, 도망
│   │   ├── InventoryManager.cs # 아이템 보유·장착·판매·드랍
│   │   ├── UpgradeManager.cs   # 스킬 구매·효과 적용
│   │   └── CurrencyManager.cs  # 골드·보석
│   ├── UI/
│   │   ├── UITheme.cs          # 색상/스타일 중앙 관리 ★
│   │   ├── UIHelper.cs         # UI 생성 유틸
│   │   ├── Panels/             # 각 탭 패널 UI
│   │   └── Elements/           # 체력바, 토스트 등 개별 요소
│   ├── Gameplay/       # TapController
│   └── Utils/          # NumberFormatter
├── Scenes/
│   └── Main.unity
├── ScriptableObjects/
│   ├── Upgrades/       # 스킬 8종
│   └── Items/          # 상점 아이템
├── Sprites/
├── Audio/
└── Resources/
    ├── Backgrounds/    # 스테이지별 배경
    ├── Monsters/       # grassland, forest 스프라이트
    └── Particles/      # hit_particles.json
```
